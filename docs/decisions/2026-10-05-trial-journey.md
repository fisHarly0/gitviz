# 看存档、开试验与返回

基线 main / 9809730，工作树干净。继续 P2 用户流程：让已有能力构成可理解的连续操作，不新增 Git 写入种类，不改变确认、锁和恢复契约。

- 插件预览提供“返回实际位置”，退出比较并定位 HEAD；明确文件变化的比较基准，避免将一次提交的改动误解为与当前工作文件的差异。
- 创建试验前说明目标版本、独立目录和原仓库保留；成功后保留路径与下一步。VS Code 明示新窗口打开及原窗口返回；桌面/DSH 支持本次会话打开试验后返回上个仓库，返回只切换浏览对象，不删除试验或撤销提交。
- 桌面沿用编辑导航保护；DSH 返回路径只由成功打开试验前的仓库记录，不接受请求任意指定路径。打开失败保留当前位置与返回入口；更换仓库清除试验导航。
- 原生三端在合成仓库验证预览、文件差异、试验创建/打开/返回，核对原仓库 HEAD/index/文件不变及试验存在；取消/失败/未完成编辑保持既有约束。最多两轮视觉检查，不宣称自动化等价于陌生用户可用性测试。
- 更新使用说明、当前交接，按既有授权提交推送。完整公开产品目标保持未完成。
