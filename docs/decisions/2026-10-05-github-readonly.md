# GitHub 只读浏览的地图与失败恢复

基线 `f1cfd90`，工作区 `F:/gitviz` / main，开始时干净。公开产品 P2 首次使用子项，沿用现有地图设计。

代码证据：旧 GitHub 图丢弃分支/标签及部分历史读取错误，按时间和第一父提交重建连线，SVG 节点没有键盘入口；远程分支和状态栏使用本地 HEAD 文案；详情缺少重试，API 未提供 patch 时显示空白对比。

本批计划：
- GitHub 复用共享版本地图，保留 API 返回的全部父边、折叠、搜索与键盘导航；明确这是已读取的远程历史和浏览基准。
- 限制并行请求，统一网络/权限/额度/空仓库错误；部分失败明确列出，保留可用内容并提供重试。切换仓库或重读时取消旧请求。
- 详情可重试；缺失 patch、文件列表可能不完整时显示限制和 GitHub 原提交链接。
- 不引入远程写入，不扩大 PAT 权限，不改变本地 Git 操作。远程仍为首批至多 100 个分支、100 个标签和每分支 100 条提交；不将其称为全历史。

验收：请求故障与取消的自动测试、已有测试/lint/三端前端构建；VS Code Integrated Browser 中真实公开仓库读取及受控 HTTP 故障、恢复、键盘选择、窄宽视口。受控响应与真实网络证据分开记录。完整 P1/P2/P3 未因此关闭。
