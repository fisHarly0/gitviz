# Windows 超时清理验收修正

基线 0a02417。CI 37337489783 的 Linux/macOS 成功，Windows 在真实恢复超时测试失败：taskkill 返回 128，并报告 Git 与子进程已经退出；生产执行器因此返回 `GIT_PROCESS_UNCERTAIN`，原测试只接受 `GIT_TIMEOUT`。此次不是前一批测试收尾清理的异常，而是被测命令内部清理的异常。

不能仅凭 taskkill 文本或输出管道关闭证明全部子进程结束，因此保留生产的保守锁策略。本批不改进程终止或 Git 写入实现，不将未知状态转为普通可重试失败。

验收计划：真实超时用例仍要求 hook 父子 PID 消失、心跳停止、HEAD/文件/index/备份/检查点正确。正常路径必须允许直接续交；Windows taskkill 128 的竞争分支必须检查会话暂停、锁保留和另一服务写入被拒绝。仅测试代码在确认自己创建的所有已知进程退出、现场一致后模拟文档中的人工清锁，再以新服务续交。其他清理异常仍失败。

新增确定性用例：真实终止后注入清理报告失败，验证相同保护与人工恢复路径，避免偶发分支从未执行。保留真实未终止进程的拒写和悬挂输出用例。局部进程测试、插件回归和 lint 通过后提交，CI 验证三系统与打包模块。首次使用和最终发行仍待推进。
