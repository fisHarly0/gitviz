# 桌面版本动作与实际位置同步

目标属于公开产品 P1：接通桌面建分支、独立 worktree 和保留历史的恢复；沿用已验证的 prepare/execute/cancel，不新增绕过确认的写入口。当前基线 main / dfa1e14，工作树干净。

## 交互与边界

- 选中节点只预览。动作面板显示当前仓库、目标存档及实际位置；建分支不切换，试验在用户选择的父目录下新建独立目录，恢复先备份再创建新提交。
- 命名和目录表单保留失败输入；确认显示目标、分支名或输出父目录。取消不执行；处理中阻止重复动作和仓库切换。
- worktree 完成后显示实际路径，用户明确点击后才在当前地图打开。原仓库的 HEAD、文件和未提交修改保持不变。
- 桌面历史快照同步分支列表、实际 HEAD 与 session；编辑期间保留编辑起点以拒绝陈旧保存，不能用刷新悄悄更新编辑基准。
- 失败显示原始诊断并刷新实际状态；恢复失败仍保留文件和备份。本批不冒充已完成操作日志和继续提交功能。

## 验收

- session 回归覆盖外部 HEAD 变化、预览保持、游离 HEAD、编辑中快照不改变保存基准。
- 原生桌面 + 隔离真实 Git 仓库验证分支创建、独立 worktree、打开试验仓库、取消恢复、恢复新提交/备份、dirty 和 stale 拒绝。
- lint、前端测试/构建及 Rust 检查和相关 Git 测试；桌面正常窗口与小窗口一次批量检查，必要时一次确认。
- 记录证据和剩余完整目标，按既有授权提交推送；不更新旧 0.2.0 发布产物。
