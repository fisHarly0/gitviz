# 存档详情与比较读取失败

基线 db28120。共享 VersionTree 的 detail/compare 请求失败只写顶部通用提示，文件区域仍显示读取中；没有针对失败请求的重试。GitHub 只读详情已有独立恢复入口，本批补齐 VS Code/DSH 共享检查器。

计划：请求结果绑定仓库快照、选中提交/比较双方与重试次数，取消订阅的旧请求不得覆盖当前显示。文件区域明确区分等待第二个节点、读取中、失败、无变化和成功；提供可键盘操作的详情/比较重试，重试只读取，不触发 Git 写入。保留现有地图和视觉结构，不新增引导弹窗。

验证：在 VS Code Integrated Browser 内加载实际构建的 VS Code 前端 bundle，以受控只读桥接覆盖失败→重试、重试中、旧请求迟到、同一 OID 切换仓库、比较方向切换和宽窄视口。该测试是实际引擎中的前端契约测试，不冒充原生 VS Code/DSH 后端端到端验收。三端前端构建、现有前端测试和 lint；最终宿主安装包仍归 P3。

键盘验收发现共享地图在布局调整时无条件聚焦节点，会打断检查器重试。同步限制焦点移动为选择/导航变化；初次挂载、窗口尺寸和缩放变化只定位视图，清理未执行的动画帧。测试验证重试区域及缩放按钮保留焦点，方向键仍聚焦选中节点。
