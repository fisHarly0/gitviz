# 跨宿主大历史支持

用户确认 2000+ 提交是正常使用场景。一次性 200/300/2000 上限不能代表完整历史，改为首批小窗口 + 显式继续加载/持续加载 + 全历史搜索定位 + 可见区域绘制。

Git 可达集合为本机 heads、remotes、tags 及 HEAD；不自动 fetch，不将浅克隆之外或无引用的悬空对象宣称为已载入历史。refs 与 HEAD 状态构成 revision，每页前后验证。写入成功后刷新为新的历史视图。

桌面以 Rust 只读 Git CLI 接入相同数据格式，共享 TreeMap，保留详情/编辑/导出。没有把新的插件恢复动作自动映射到旧桌面写入，也没有改变点击预览语义。原有横竖切换保留。

性能验证以真实 fast-import 合成仓库为基础，完整翻页、跨页合并、全局搜索、旧 HEAD 和可见 DOM 数量同时验证。默认每批 300，单批最大 2000 是流量界限，不是仓库总数界限。10k 数据为本批实测规模，不承诺任意规模无延迟。
