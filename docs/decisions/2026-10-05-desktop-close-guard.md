# 桌面关闭保护

基线 main / 3e8c0c3，工作树干净。公开交付 P1 的下一批只处理桌面正常关闭与操作/编辑生命周期，不关闭完整 P1/P2/P3 清单。

## 行为与边界

- 主窗口正常关闭事件先交由前端判断；无未保存编辑时关闭，有内容或提交说明草稿时复用现有确认框，取消保留原缓冲。明确放弃后只关闭窗口，已创建的分支、磁盘文件、index 与操作记录保留。
- Git 操作、待确认动作和整个导出流程占用同一执行门禁。关闭请求不能覆盖已有确认或中断执行；提示用户先完成或取消。关闭确认自己也占用门禁，重复关闭请求合并，防止关闭途中启动新的写入。
- 草稿状态在编辑事件中同步记录，避免等待异步渲染后才知道有修改；挂载/卸载按编辑器生命周期清理。关闭监听未准备好或注册失败时阻止本地写入并显示原因。
- 使用安装依赖中 Tauri `onCloseRequested` 和 `destroy`；capability 仅对既有 main 窗口增加 `core:window:allow-destroy`。不增加文件系统、shell 或任意窗口创建权限。
- 当前批次保护正常窗口关闭，不承诺阻止进程强制终止、系统断电或 Webview 崩溃，也不把内存编辑自动写入 Git。

## 验收

纯逻辑测试检查取消、重复请求、已有操作不被替换、关闭失败后的重试；真实 Tauri 窗口用 Windows WM_CLOSE 请求关闭，不伪造关闭事件或 Git IPC。合成仓库验证未编辑正常关闭、草稿取消/放弃、提交失败后的文件保留、Git 确认和运行中 hook 阻止关闭、提交完成后关闭。构建、lint 和必要回归通过后再更新状态与推送。
