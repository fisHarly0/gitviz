# 桌面关闭与未保存编辑

开发版桌面程序处理普通的窗口关闭请求（关闭按钮、Alt+F4）。它不会自动保存文件或创建提交。

| 关闭时的状态 | 应用行为 |
|---|---|
| 没有未保存的文件内容或提交说明 | 直接关闭；仅打开编辑器但未修改也可直接关闭 |
| 存在编辑内容或提交说明草稿 | 显示“关闭并放弃未保存的编辑？”；默认焦点在取消，Escape 也取消 |
| Git 操作、导出或确认正在进行 | 保持窗口，提示先完成或取消；已有确认不会被替换 |
| 已在确认是否关闭 | 再次关闭不会重复打开确认框 |

取消关闭后，编辑器内容和提交说明原样保留。选择“放弃编辑并关闭”仅丢弃内存中的草稿，不删除已经创建的分支、文件、暂存内容或操作记录。若 Git hook 拒绝了提交，文件可能已经写入并暂存，关闭不会撤销这些更改；下次打开仓库仍可通过 [操作记录与恢复](operation-recovery.md) 检查和继续。

Git 操作结束后不会自动执行先前被阻止的关闭请求，需要再次关闭窗口。导出从读取对象、选择保存位置到压缩和写入完成都占用执行门禁；导出期间不能切换仓库或启动另一项写入。正在编辑时先完成或取消编辑，再导出已提交的分支。

关闭保护必须成功注册后才能执行本地写入；启动失败会在界面显示错误并暂停本地操作，请重启应用。关闭本身失败时显示原因，可重新尝试。

此保护仅适用于桌面版正常窗口关闭，不涵盖强制结束进程、系统断电或 WebView 崩溃。VS Code 和 DSH 的宿主退出不由桌面监听处理。旧 0.2.0 二进制包不包含本次开发版更新。

## 运行关闭冒烟测试

需要 Windows、构建后的 Tauri 可执行文件及 Playwright Core。脚本自行启动并关闭独立应用与 WebView2 配置，仅操作新建的合成仓库。9248 端口必须空闲；不得指向日常应用或真实仓库。

```powershell
$env:GITVIZ_DESKTOP_EXECUTABLE='F:\gitviz\src-tauri\target\release\gitviz.exe'
$env:GITVIZ_DESKTOP_TEST_ROOT='F:\Codex\work\gitviz-product\close-tests'
$env:PLAYWRIGHT_CORE_PATH='F:\gitviz-work\browser-check\node_modules\playwright-core'
node tests/desktop-close-smoke.cjs
```

测试通过 Windows `WM_CLOSE` 请求真实窗口关闭，Git IPC 不作模拟。覆盖无修改关闭、提交说明草稿、重复关闭、取消保留、明确放弃、已有 Git/编辑确认、实际运行中的 hook、原生导出保存框与取消、成功提交后关闭，以及 hook 失败后关闭仍保留文件/index/恢复记录。原生保存框通过同一测试进程的取消消息关闭，不写出 ZIP；本轮不重复验证导出文件内容。结果和截图写入指定目录；脚本清理范围仅为自己启动的应用进程。
