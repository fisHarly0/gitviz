## 已实现

- `package.json` / lock：Node 引擎约束，`desktop:dev`、`desktop:build`、`desktop:bundle` 和 `test` 入口。
- `RepoLoader` / GitHub adapter：按运行环境选择可用入口，浏览器禁用本地打开；表单加载锁、回车提交、输入校验、空仓库/权限提示、15 秒请求超时及 sessionStorage 不可用时的降级。
- `App` / session：提交后切仓库重置刷新状态；本地按真实当前分支初始化；选中 HEAD 可查看详情；正确清理延迟完成的拖放监听。
- 分支栏与提示：GitHub 只读不显示导出、编辑引导；分支切换错误可见；增加键盘焦点和禁用样式。
- Rust `get_commit_detail`：将反向 new → old 比较修正为 old → new；修复新增显示为删除、编辑入口缺失和差异内容反向的问题。
- README/TUTORIAL：以当前 Tauri/gix 实现为准，补运行模式、构建前提、命令、真实截图、GitHub 历史读取上限及真实工作文件写入说明。
